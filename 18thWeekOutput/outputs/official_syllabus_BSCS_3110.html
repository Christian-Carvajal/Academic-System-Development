Course Syllabus: BSCS 3110
I. Course Identification & Specification
Course Code BSCS 3110 Course Title Information Assurance and Security
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 2207 (Data Communications and Networking)
Course Description Core principles of cybersecurity and information assurance, focusing on the CIA triad (Confidentiality, Integrity, Availability), symmetric and asymmetric cryptography, public key infrastructure (PKI), secure network architectures, threat modeling, vulnerability assessment, intrusion detection systems, and institutional security governance.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Analyze computing problems and apply fundamental cybersecurity principles to protect data confidentiality, integrity, and availability. Apply PLO1
CLO2 Design secure network architectures utilizing symmetric and asymmetric cryptography within a Public Key Infrastructure (PKI). Create PLO5
CLO3 Evaluate vulnerability assessment tools and intrusion detection systems to mitigate identified security threats. Evaluate PLO1, PLO4
CLO4 Implement institutional security governance frameworks ensuring professional responsibility and informed judgment in computing practice. Apply PLO4, PLO5
III. 18-Week Semester Instructional Matrix
Wk Topics Covered Lesson Learning Outcomes (LLOs) TLAs & Exercises Assessment & Evidence
1 Introduction to Information Assurance
  • K Define the CIA triad and its relevance to data protection.
  • S Identify common security threats in computing environments.
  • A Demonstrate professional responsibility regarding data privacy.
  • Lecture on CIA Triad
  • Case Study Discussion
  • Quiz on Security Fundamentals
2 Risk Management and Threat Assessment
  • K Calculate risk exposure using probability and impact matrices.
  • S Formulate mitigation strategies for identified vulnerabilities.
  • A Adhere to ethical guidelines in risk reporting.
  • Risk Calculation Lab
  • Group Risk Analysis
  • Risk Assessment Worksheet
3 Access Control Models
  • K Compare Discretionary and Mandatory Access Control models.
  • S Configure access control policies on Linux systems.
  • A Respect user privacy during authentication processes.
  • Lab: Access Control Configuration
  • Policy Configuration Report
4 Symmetric Cryptography Fundamentals
  • K Explain encryption algorithms like AES and DES.
  • S Implement symmetric encryption using OpenSSL tools.
  • A Maintain confidentiality integrity in data transmission.
  • Encryption Lab Exercise
  • Cipher Implementation Test
5 Asymmetric Cryptography and Digital Signatures
  • K Analyze RSA and ECC key generation processes.
  • S Generate digital signatures for document verification.
  • A Uphold trust in digital communication protocols.
  • Digital Signature Lab
  • Signature Verification Quiz
6 Public Key Infrastructure (PKI) Design
  • K Design a PKI architecture with Certificate Authorities.
  • S Create and manage digital certificates using CA tools.
  • A Ensure compliance with certificate lifecycle policies.
  • PKI Design Workshop
  • Architecture Diagram Submission
7 Vulnerability Assessment Tools
  • K Evaluate the functionality of Nmap and Nessus.
  • S Scan networks for open ports and misconfigurations.
  • A Report findings without compromising system integrity.
  • Vulnerability Scanning Lab
  • Scan Report Analysis
8 Intrusion Detection Systems (IDS)
  • K Differentiate between signature and anomaly-based IDS.
  • S Configure Snort rules for traffic monitoring.
  • A Respond to alerts with professional judgment.
  • IDS Configuration Lab
  • Alert Response Simulation
9 Midterm Examination
  • K Demonstrate mastery of Weeks 1-8 concepts.
  • S Apply security principles in exam scenarios.
  • A Maintain academic integrity during assessment.
  • Midterm Examination
  • Written Midterm Exam
10 Security Governance Frameworks
  • K Formulate security policies for organizational structure.
  • S Draft incident response plans and procedures.
  • A Commit to following institutional security protocols.
  • Policy Drafting Workshop
  • Policy Draft Submission
11 Compliance and Auditing
  • K Analyze compliance requirements for PCI-DSS and HIPAA.
  • S Conduct internal security audits using checklists.
  • A Respect confidentiality during audit processes.
  • Audit Simulation Lab
  • Compliance Checklist Review
12 Security Governance Implementation
  • K Implement security governance frameworks in practice.
  • S Execute security audits and generate compliance reports.
  • A Demonstrate informed judgment in governance decisions.
  • Governance Implementation Lab
  • Compliance Report Submission
13 Capstone Project: Security Architecture Design
  • K Design a secure network architecture for a client.
  • S Integrate cryptography and PKI into the design.
  • A Apply professional ethics in project planning.
  • Capstone Design Workshop
  • Design Proposal Submission
14 Capstone Project: Vulnerability Assessment
  • K Assess vulnerabilities in the designed architecture.
  • S Utilize IDS tools to test security controls.
  • A Prioritize risks based on impact and likelihood.
  • Vulnerability Assessment Lab
  • Assessment Report Submission
15 Capstone Project: Governance & Policy
  • K Formulate security policies for the client environment.
  • S Implement governance frameworks and audit procedures.
  • A Ensure adherence to professional responsibility standards.
  • Policy Implementation Workshop
  • Governance Framework Submission
16 Capstone Project Review and Refinement
  • K Evaluate project security against industry standards.
  • S Refine architecture and policies based on feedback.
  • A Demonstrate commitment to continuous improvement.
  • Peer Review Session
  • Refinement Report Submission
17 Capstone Project Presentation Preparation
  • K Prepare comprehensive presentation materials.
  • S Deliver technical defense of the security architecture.
  • A Communicate security concepts clearly to stakeholders.
  • Presentation Rehearsal
  • Presentation Rubric Checklist
18 Final Examination & Capstone Defense
  • K Demonstrate comprehensive knowledge of course content.
  • S Defend the capstone project before the board.
  • A Uphold academic integrity during final assessment.
  • Final Examination & Defense
  • Written Final Exam & Oral Defense
