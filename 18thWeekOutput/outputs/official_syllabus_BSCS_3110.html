Course Syllabus: BSCS 3110
I. Course Identification & Specification
Course Code BSCS 3110 Course Title Information Assurance and Security
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 2207 (Data Communications and Networking)
Course Description Core principles of cybersecurity and information assurance, focusing on the CIA triad (Confidentiality, Integrity, Availability), symmetric and asymmetric cryptography, public key infrastructure (PKI), secure network architectures, threat modeling, vulnerability assessment, intrusion detection systems, and institutional security governance.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Analyze computing problems and apply cybersecurity fundamentals to identify risks within complex systems. Analyze PLO1
CLO2 Implement symmetric and asymmetric cryptographic protocols within secure network architectures using PKI standards. Apply PLO5
CLO3 Evaluate intrusion detection systems and vulnerability assessment tools against established threat models. Evaluate PLO1, PLO5
CLO4 Create institutional security governance policies aligned with professional responsibilities and legal compliance. Create PLO4
III. 18-Week Semester Instructional Matrix
Wk Topics Covered Lesson Learning Outcomes (LLOs) TLAs & Exercises Assessment & Evidence
1 Introduction to Information Assurance, Risk Assessment Fundamentals
  • K Analyze computing environments to identify potential security risks.
  • S Design a risk assessment matrix for organizational assets.
  • A Demonstrate professional responsibility in safeguarding data integrity.
  • Lecture on Risk Theory
  • Case Study Analysis
  • Risk Identification Quiz
2 Threat Modeling, Vulnerability Classification
  • K Evaluate threat vectors against system architectures.
  • S Map vulnerabilities to specific attack scenarios.
  • A Adhere to ethical standards during threat assessment.
  • Group Discussion on Threats
  • Vulnerability Scanning Lab
  • Threat Model Draft
3 Symmetric Cryptography, Encryption Algorithms
  • K Explain mathematical principles of symmetric encryption.
  • S Implement AES encryption protocols using standard libraries.
  • A Maintain confidentiality in all cryptographic operations.
  • Algorithm Simulation Lab
  • Code Review
  • Encryption Implementation Task
4 Asymmetric Cryptography, Public Key Infrastructure
  • K Compare RSA and ECC key generation methods.
  • S Configure PKI infrastructure for digital signatures.
  • A Uphold trust principles in certificate validation.
  • PKI Setup Lab
  • Certificate Authority Simulation
  • Key Generation Report
5 Secure Network Architectures, Firewall Configuration
  • K Design network topologies for data protection.
  • S Implement firewall rules to restrict unauthorized access.
  • A Respect network security policies during configuration.
  • Network Simulation Lab
  • Policy Review
  • Firewall Rule Set Design
6 Secure Communication Protocols, TLS/SSL Implementation
  • K Analyze handshake processes in TLS protocols.
  • S Configure secure web servers with valid certificates.
  • A Ensure privacy compliance in communication channels.

  • Protocol Analysis

  • K Identify IDS types and their operational mechanisms.
