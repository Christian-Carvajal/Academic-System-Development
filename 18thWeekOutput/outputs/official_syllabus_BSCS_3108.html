Course Syllabus: BSCS 3108
I. Course Identification & Specification
Course Code BSCS 3108 Course Title Automata Theory and Formal Languages
Credit Units 3 Units (Lecture: 3 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 2106 (Discrete Mathematics)
Course Description Rigorous theoretical exploration of computational models and formal grammars, covering regular expressions, deterministic and non-deterministic finite automata (DFA/NFA), context-free grammars, pushdown automata, Turing machines, decidability, the Halting problem, and the Chomsky hierarchy.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Analyze computational models to construct deterministic finite automata (DFA) and regular expressions for language recognition. Analyze PLO1, PLO5
CLO2 Apply context-free grammars to design pushdown automata and solve parsing problems for formal languages. Apply PLO1, PLO5
CLO3 Evaluate the decidability of computational problems using Turing machines and assess the Halting problem constraints. Evaluate PLO1, PLO5
CLO4 Design formal grammars within the Chomsky hierarchy to create new computational models for complex systems. Create PLO1, PLO5
III. 18-Week Semester Instructional Matrix
Wk Topics Covered Lesson Learning Outcomes (LLOs) TLAs & Exercises Assessment & Evidence
1 Introduction to Automata & Regular Languages
  • K Define formal languages and construct deterministic finite automata (DFA) from regular expressions.
  • S Convert regular expressions to equivalent DFAs using Thompson's construction.
  • A Demonstrate appreciation for logical precision in computational modeling.
  • Lecture on Formal Systems
  • Lab: DFA Construction
  • Quiz on Regular Expressions
2 DFA Minimization and Properties
  • K Analyze DFA states to minimize automata using Hopcroft's algorithm.
  • S Implement state minimization procedures in simulation software.
  • A Value efficiency and optimization in system design.
  • Algorithm Workshop
  • Group Discussion
  • Lab Report on Minimization
3 Regular Language Closure Properties
  • K Evaluate closure properties of regular languages under union and concatenation.
  • S Construct DFAs for complex expressions derived from simple ones.
  • A Respect mathematical rigor in logical proofs.
  • Proof Writing Exercise
  • Case Study
  • Short Answer Quiz
4 Nondeterministic Finite Automata (NFA)
  • K Convert NFAs to equivalent DFAs using subset construction.
  • S Design NFA models for pattern matching applications.
  • A Appreciate the trade-offs between determinism and flexibility.
  • Conversion Lab
  • Peer Review
  • Lab Submission

  • S Parse strings using recursive descent parsing algorithms.
