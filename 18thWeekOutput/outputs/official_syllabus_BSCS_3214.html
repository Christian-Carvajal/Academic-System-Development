Course Syllabus: BSCS 3214
I. Course Identification & Specification
Course Code BSCS 3214 Course Title Data Visualization
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites BSCS 3111 (Data Mining)
Course Description Theories and hands-on practices of visual data analytics and graphical storytelling, including visual perception cognition, the Grammar of Graphics, interactive dashboard construction, exploratory plotting with modern tools (Plotly, D3.js, Seaborn), multidimensional and geospatial visualization, and effective communication of data insights.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Design complex visual interfaces adhering to the Grammar of Graphics standards for optimal data representation. Create PLO2, PLO5
CLO2 Implement interactive dashboards using Plotly and D3.js libraries to process multidimensional datasets. Apply PLO2, PLO5
CLO3 Analyze visual perception cognition to enhance the clarity and interpretability of graphical data presentations. Analyze PLO3, PLO5
CLO4 Evaluate the efficacy of data storytelling techniques in conveying quantitative insights to diverse audiences. Evaluate PLO3
III. 18-Week Semester Instructional Matrix
Wk Topics Covered Lesson Learning Outcomes (LLOs) TLAs & Exercises Assessment & Evidence
1 Introduction to Data Visualization & Grammar of Graphics
  • K Define the principles of visual encoding for data representation.
  • S Construct basic charts using Python and Pandas libraries.
  • A Demonstrate ethical considerations in data presentation.
  • Lecture on Visual Perception
  • Quiz on Visualization Ethics
2 Data Types & Encoding Scales
  • K Categorize data types and select appropriate encoding scales.
  • S Map categorical and numerical data to visual channels.
  • A Appreciate the impact of color on audience interpretation.
  • Lab Exercise on Chart Selection
  • Formative Assessment Rubric
3 Visualizing Relationships & Trends
  • K Analyze correlations between variables using scatter plots.
  • S Implement regression analysis visualizations in Python.
  • A Evaluate the clarity of trend lines in complex datasets.
  • Lab Exercise on Correlation Analysis
  • Formative Assessment Rubric
4 Introduction to Plotly & Interactive Elements
  • K Describe the architecture of interactive web dashboards.
  • S Create static plots using Plotly Express library.
  • A Adhere to accessibility standards in dashboard design.
  • Lab Exercise on Plotly Basics
  • Formative Assessment Rubric
5 Interactive Dashboards & Layouts
  • K Design dashboard layouts for multidimensional datasets.
  • S Implement interactive filters and zoom features in Plotly.
  • A Collaborate effectively during group dashboard creation.
  • Lab Exercise on Dashboard Layout
  • Formative Assessment Rubric
6 Advanced Plotly Features & Geospatial Data
  • K Identify geospatial data requirements for visualization.
  • S Map geospatial datasets using Plotly maps.
  • A Respect privacy when visualizing sensitive location data.
  • Lab Exercise on Geospatial Mapping
  • Formative Assessment Rubric
7 Introduction to D3.js & SVG Manipulation
  • K Explain the DOM structure required for D3.js.
  • S Manipulate SVG elements using D3.js syntax.
  • A Demonstrate patience when debugging JavaScript code.
  • Lab Exercise on D3.js Basics
  • Formative Assessment Rubric
8 Customizing Visuals with D3.js
  • K Design custom visual encodings using D3 scales.
  • S Implement custom transitions and animations in D3.js.
  • A Critique the aesthetic impact of animation speed.
  • Lab Exercise on Custom Transitions
  • Formative Assessment Rubric
9 Midterm Examination
  • K Assess mastery of Grammar of Graphics concepts.
  • S Evaluate proficiency in Plotly and D3.js tools.

  • Midterm Examination
  • Summative Assessment Rubric
10 Data Storytelling Fundamentals
  • K Formulate a narrative arc for quantitative data.
  • S Draft a story outline based on dataset insights.

  • Story Outline Rubric
