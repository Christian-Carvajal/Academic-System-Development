Course Syllabus: BSCS 3214
I. Course Identification & Specification
Course Code BSCS 3214 Course Title Data Visualization
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites BSCS 3111 (Data Mining)
Course Description Theories and hands-on practices of visual data analytics and graphical storytelling, including visual perception cognition, the Grammar of Graphics, interactive dashboard construction, exploratory plotting with modern tools (Plotly, D3.js, Seaborn), multidimensional and geospatial visualization, and effective communication of data insights.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Analyze visual perception principles and grammar of graphics to interpret data structures. Analyze PLO5
CLO2 Apply modern visualization libraries (Plotly, D3.js) to construct functional interactive dashboards. Apply PLO2
CLO3 Evaluate the effectiveness of visual representations in communicating quantitative findings. Evaluate PLO3
CLO4 Create multidimensional geospatial visualizations to solve complex data problems. Create PLO2, PLO5
