Course Syllabus: CS 3110
I. Course Identification & Specification
Course Code CS 3110 Course Title Data Structures and Algorithms
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 2110 (Computer Programming 2)
Course Description Comprehensive study of abstract data types, recursive algorithms, dynamic memory allocation, trees, sorting algorithms, and Big-O computational complexity.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Formulate and optimize time and space complexity models. Analyze PLO1, PLO2
CLO2 Design recursive algorithms to solve complex computational problems efficiently. Create PLO1, PLO3
CLO3 Evaluate the time and space complexity of sorting algorithms using Big-O notation. Evaluate PLO2, PLO4
CLO4 Implement tree data structures to organize and retrieve hierarchical information systematically. Apply PLO1, PLO3
