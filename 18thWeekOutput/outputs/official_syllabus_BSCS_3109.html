Course Syllabus: BSCS 3109
I. Course Identification & Specification
Course Code BSCS 3109 Course Title Operating System Configuration and Use
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 2108 (Computer Architecture and Organization)
Course Description Comprehensive study of operating system architectures and system configuration, encompassing process scheduling, multithreading, concurrency synchronization, deadlock avoidance, memory virtualization, paging, file system structures, device management, and hands-on Linux/Unix shell administration.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Analyze operating system architectures and configuration parameters to optimize system performance metrics. Analyze PLO1, PLO5
CLO2 Create automated Linux/Unix shell scripts for complex system administration tasks. Create PLO2, PLO5
CLO3 Evaluate memory virtualization and file system structures regarding data integrity and security protocols. Evaluate PLO1, PLO2
CLO4 Apply concurrency synchronization mechanisms to resolve deadlock avoidance in multithreaded environments. Apply PLO2, PLO5
