Course Syllabus: BSCS 3213
I. Course Identification & Specification
Course Code BSCS 3213 Course Title Software Engineering
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 3110 (Data Structures and Algorithms)
Course Description Systematic engineering methodologies for software development, covering SDLC models, Agile/Scrum frameworks, requirements engineering, object-oriented analysis and design with UML, architectural patterns, unit and integration testing, continuous integration and deployment (CI/CD), and software project management.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Design scalable software architectures using Agile frameworks and SDLC models to solve complex problems. Create PLO2, PLO5
CLO2 Analyze system requirements and construct UML diagrams for object-oriented design specifications. Analyze PLO2, PLO3
CLO3 Implement automated testing protocols and configure continuous integration/deployment pipelines. Apply PLO2, PLO5
CLO4 Evaluate project management strategies to ensure alignment with engineering best practices. Evaluate PLO3, PLO5
