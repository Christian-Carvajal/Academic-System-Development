Course Syllabus: BSCS 3215
I. Course Identification & Specification
Course Code BSCS 3215 Course Title Parallel and Distributed Computing
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites BSCS 3109 (Operating System Configuration and Use)
Course Description Foundational principles and architectures of concurrent, parallel, and distributed computing systems. Topics encompass Flynn's taxonomy, shared-memory programming (OpenMP/pthreads), distributed-memory message passing (MPI), massively parallel GPU programming (CUDA), distributed consensus algorithms, cloud cluster parallelism, and performance scalability metrics.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
