Course Syllabus: BSCS 3111
I. Course Identification & Specification
Course Code BSCS 3111 Course Title Data Mining
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 3112 (Database Systems 1)
Course Description Principles, algorithms, and applications of knowledge discovery in databases (KDD), including data cleaning and preprocessing, exploratory data analysis, ETL pipelines, association rule mining (Apriori, FP-Growth), classification algorithms (Decision Trees, Naive Bayes, SVM), clustering techniques (K-Means, DBSCAN), and evaluation metrics.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Implement ETL pipelines and data preprocessing techniques to ensure dataset quality for analysis. Apply PLO1, PLO5
CLO2 Design and configure association rule mining algorithms and classification models to solve specific business problems. Create PLO1, PLO2
CLO3 Evaluate the performance of clustering algorithms using appropriate metrics and interpret results for decision making. Evaluate PLO1, PLO2
CLO4 Formulate comprehensive data-driven solutions by integrating mining techniques into large-scale analytical frameworks. Create PLO1, PLO2, PLO5
