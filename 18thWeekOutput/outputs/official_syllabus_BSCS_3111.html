Course Syllabus: BSCS 3111
I. Course Identification & Specification
Course Code BSCS 3111 Course Title Data Mining
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 3112 (Database Systems 1)
Course Description Principles, algorithms, and applications of knowledge discovery in databases (KDD), including data cleaning and preprocessing, exploratory data analysis, ETL pipelines, association rule mining (Apriori, FP-Growth), classification algorithms (Decision Trees, Naive Bayes, SVM), clustering techniques (K-Means, DBSCAN), and evaluation metrics.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Implement ETL pipelines and perform data cleaning to prepare datasets for analysis. Apply PLO1, PLO5
CLO2 Analyze large datasets using association rule mining and classification algorithms to extract patterns. Analyze PLO1, PLO2
CLO3 Evaluate clustering techniques and model performance using appropriate metrics for accuracy and precision. Evaluate PLO1, PLO2
CLO4 Design a comprehensive knowledge discovery in databases (KDD) project integrating data mining techniques. Create PLO1, PLO2, PLO5
III. 18-Week Semester Instructional Matrix
Wk Topics Covered Lesson Learning Outcomes (LLOs) TLAs & Exercises Assessment & Evidence
1 Introduction to Data Mining, Data Characteristics
  • K Define the scope and objectives of data mining projects.
  • S Configure development environments using IDEs and version control.
  • A Demonstrate professional ethics in data handling and privacy.
  • Lecture on Data Mining Concepts
  • Participation Rubric
2 Data Types and Structures, Exploratory Data Analysis
  • K Categorize data into structured, semi-structured, and unstructured formats.
  • S Construct exploratory analysis reports using statistical tools.
  • A Adhere to academic integrity during data exploration tasks.
  • Lab Exercise on Data Exploration
  • Lab Report Submission
3 Data Preprocessing Fundamentals, Handling Missing Values
  • K Identify missing data patterns and their impact on analysis.
  • S Implement imputation strategies for incomplete datasets.
  • A Prioritize data quality over speed in preprocessing workflows.
  • Lab Exercise on Imputation Techniques
  • Preprocessing Code Review
4 ETL Pipeline Design, Data Transformation
  • K Map extraction requirements to source database schemas.
  • S Develop automated ETL scripts for data extraction and loading.
  • A Collaborate effectively within a team to design pipelines.
  • Group Project: Pipeline Design
  • Pipeline Architecture Diagram
5 Data Cleaning Strategies, Outlier Detection
  • K Analyze causes of data inconsistencies and errors.
  • S Apply statistical methods to detect and remove outliers.
  • A Maintain objectivity when correcting erroneous data records.
  • Lab Exercise on Outlier Removal
  • Cleaned Dataset Validation
6 Feature Engineering, Dimensionality Reduction
  • K Select relevant features for predictive modeling.
  • S Engineer new features to enhance model performance.
  • A Respect intellectual property when using public datasets.
  • Lab Exercise on Feature Selection
  • Feature Importance Analysis
7 Data Integration, Schema Merging
  • K Resolve conflicts when merging heterogeneous data sources.
  • S Integrate multiple datasets into a unified schema.
  • A Communicate technical constraints to stakeholders clearly.
  • Lab Exercise on Data Integration
  • Integrated Dataset Report
8 ETL Pipeline Optimization, CLO1 Review, Midterm Prep
  • K Evaluate the efficiency of current ETL processes.
  • S Optimize pipeline execution times and resource usage.
  • A Demonstrate readiness for assessment through self-review.
  • Midterm Examination Preparation
  • Formative Assessment Rubric
9 Midterm Examination, Review of CLO1
  • K Assess understanding of ETL and data cleaning concepts.
  • S Evaluate performance on applied ETL tasks under timed conditions.
  • A Maintain composure and focus during the examination.
  • Midterm Examination
  • Summative Assessment
10 Association Rule Mining, Apriori Algorithm
  • K Explain the principles of association rule mining.
  • S Implement Apriori algorithm to discover itemsets.
  • A Interpret business rules derived from transaction data.
  • Lab Exercise on Association Rules
  • Rule Discovery Report
11 Classification Algorithms, Supervised Learning
  • K Compare classification algorithms for binary and multi-class problems.
  • S Train classifiers using labeled datasets.
  • A Justify algorithm selection based on problem constraints.
  • Lab Exercise on Classification
  • Model Training Log
12 Evaluation Metrics, Accuracy and Precision
  • K Calculate accuracy, precision, recall, and F1-score.
  • S Visualize model performance using confusion matrices.
  • A Critique model reliability based on metric thresholds.
  • Lab Exercise on Metrics Calculation
  • Confusion Matrix Analysis
13 Clustering Techniques, K-Means Algorithm
  • K Differentiate between partitioning and hierarchical clustering.
  • S Apply K-Means algorithm to group unlabeled data.
  • A Validate cluster quality using internal metrics.
  • Lab Exercise on Clustering
  • Cluster Visualization
14 Clustering Evaluation, Silhouette Score
  • K Assess the effectiveness of clustering results.
  • S Optimize cluster count using silhouette scores.
  • A Present findings with confidence and clarity.
  • Lab Exercise on Cluster Evaluation
  • Optimization Report
15 KDD Process, Data Mining Project Phase 1
  • K Outline the steps of the Knowledge Discovery in Databases process.
  • S Design a comprehensive KDD project proposal.
  • A Demonstrate commitment to project milestones and deadlines.
  • Capstone Project Kickoff
  • Project Proposal Submission
16 KDD Project Phase 2, Model Integration
  • K Integrate multiple data mining techniques into a single system.
  • S Develop and deploy integrated models for the project.
  • A Ensure data security within the integrated system.
  • Capstone Project Development
  • System Integration Log
17 KDD Project Phase 3, Final Review
  • K Analyze project results against initial objectives.
  • S Refine the final project deliverables based on feedback.
  • A Prepare for defense presentation with professionalism.
  • Capstone Project Review
  • Final Project Rubric
18 Final Examination & Capstone Defense, Course Closure
  • K Evaluate comprehensive knowledge of data mining concepts.
  • S Defend the capstone project before a panel of experts.
  • A Reflect on personal growth and course achievements.
  • Final Examination & Capstone Defense
  • Summative Assessment
