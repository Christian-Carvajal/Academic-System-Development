Course Syllabus: BSCS 3112
I. Course Identification & Specification
Course Code BSCS 3112 Course Title Artificial Intelligence
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 3110 (Data Structures and Algorithms)
Course Description Foundational and modern principles of artificial intelligence, including intelligent agents, state-space search heuristics (A*, Minimax), knowledge representation, first-order logic, probabilistic reasoning, machine learning pipelines, deep neural networks, computer vision, natural language processing, and ethical considerations in autonomous systems.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Analyze the principles of intelligent agents and state-space search heuristics to solve complex computing problems. Analyze PLO1, PLO5
CLO2 Create machine learning pipelines and deep neural network architectures for computer vision and natural language processing tasks. Create PLO1, PLO2
CLO3 Apply first-order logic and probabilistic reasoning to formulate knowledge representation systems for autonomous agents. Apply PLO1, PLO5
CLO4 Evaluate the ethical implications of AI systems and communicate professional solutions in various computing contexts. Evaluate PLO1, PLO3
III. 18-Week Semester Instructional Matrix
Wk Topics Covered Lesson Learning Outcomes (LLOs) TLAs & Exercises Assessment & Evidence
1 Introduction to AI and Intelligent Agents
  • K Define intelligent agents and their environments.
  • S Trace agent behavior in different environments.
  • A Appreciate the autonomy of autonomous systems.
  • Lecture on Agent Types
  • Quiz on Agent Definitions
2 State-Space Search Algorithms
  • K Analyze state-space representation for problems.
  • S Implement Breadth-First Search (BFS).
  • A Value computational efficiency in search.
  • Lab: BFS Implementation
  • Lab Report on Search Complexity
3 Heuristics and A* Search
  • K Formulate admissible heuristics for pathfinding.
  • S Apply A* algorithm to solve mazes.
  • A Recognize limitations of heuristic search.
  • Lab: A* Pathfinding
  • Midterm Exam Preparation Quiz
4 Introduction to Knowledge Representation
  • K Define predicates and quantifiers.
  • S Construct logical formulas from sentences.
  • A Respect the rigor of formal logic.
  • Lecture on Propositional Logic
  • Homework: Logic Translation
5 First-Order Logic and Inference
  • K Translate natural language to FOL.
  • S Build knowledge bases using FOL.
  • A Value accuracy in representation.
  • Lab: Prolog Programming
  • Quiz on FOL Syntax
6 Probabilistic Reasoning and Bayesian Nets
  • K Calculate conditional probabilities.
  • S Apply Bayesian networks to inference.
  • A Acknowledge uncertainty in data.
  • Lab: BN Construction
  • Homework on Probability
7 Machine Learning Fundamentals
  • K Identify supervised vs unsupervised tasks.
  • S Prepare datasets for training.
  • A Understand data importance in ML.
  • Lecture on ML Pipelines
  • Dataset Preparation Task
8 Deep Neural Networks Architecture
  • K Define layers and activation functions.
  • S Build neural network architectures.
  • A Appreciate model complexity.
  • Lab: NN Design
  • Architecture Design Proposal
9 Midterm Examination
  • K Review course concepts comprehensively.
  • S Demonstrate knowledge via assessment.
  • A Maintain academic integrity during exam.
  • Midterm Examination
  • Formative Assessment Rubric
10 Computer Vision Applications
  • K Identify visual features for tasks.
  • S Implement Convolutional Neural Networks (CNNs).

  • Lab: Image Classification

11 Natural Language Processing
