Course Syllabus: BSCS 3112
I. Course Identification & Specification
Course Code BSCS 3112 Course Title Artificial Intelligence
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 3110 (Data Structures and Algorithms)
Course Description Foundational and modern principles of artificial intelligence, including intelligent agents, state-space search heuristics (A*, Minimax), knowledge representation, first-order logic, probabilistic reasoning, machine learning pipelines, deep neural networks, computer vision, natural language processing, and ethical considerations in autonomous systems.
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Formulate advanced intelligent agents using heuristic search algorithms. Apply PLO1, PLO2
CLO2 Evaluate the effectiveness of knowledge representation methods and probabilistic reasoning in first-order logic. Analyze PLO1, PLO3
CLO3 Create machine learning pipelines integrating deep neural networks for computer vision and natural language processing tasks. Create PLO1, PLO4
CLO4 Assess ethical implications of autonomous systems and formulate guidelines for responsible AI deployment. Evaluate PLO2, PLO5
III. 18-Week Semester Instructional Matrix
Wk Topics Covered Lesson Learning Outcomes (LLOs) TLAs & Exercises Assessment & Evidence
1 Introduction to AI and Search Problems
  • K Define intelligent agents and state-space search problems.
  • S Model search problems using graph representations.
  • A Demonstrate professional curiosity in AI applications.
  • Lecture on Agent Frameworks
  • Quiz on Search Concepts
2 Uninformed Search Algorithms
  • K Compare Breadth-First and Depth-First search strategies.
  • S Implement uninformed search algorithms in Python.
  • A Appreciate algorithmic efficiency in problem solving.
  • Lab on Search Implementation
  • Code Review
3 Heuristic Search and A* Algorithm
  • K Analyze admissible and consistent heuristics.
  • S Design A* search agents for pathfinding tasks.
  • A Value heuristic accuracy in real-world scenarios.
  • Lab on Heuristic Design
  • Search Algorithm Report
4 Minimax and Alpha-Beta Pruning
  • K Explain game-theoretic decision making.
  • S Code Minimax agents with pruning techniques.
  • A Respect computational constraints in game design.
  • Lab on Game AI
  • Game Simulation Output
5 Informed Search Optimization
  • K Evaluate search algorithm performance metrics.
  • S Optimize search paths using bidirectional methods.
  • A Demonstrate commitment to efficient resource usage.
  • Lab on Optimization
  • Performance Analysis
6 Constraint Satisfaction Problems
  • K Formulate CSPs for scheduling scenarios.
  • S Implement backtracking algorithms for CSPs.
  • A Acknowledge complexity in constraint management.
  • Lab on CSP Solving
  • Constraint Solver Code
7 Probabilistic Reasoning and Logic
  • K Represent uncertainty using probability theory.
  • S Construct Bayesian networks for inference.
  • A Adopt evidence-based decision making.
  • Lab on Probability Modeling
  • Bayesian Network Diagram
8 First-Order Logic and Knowledge Representation
  • K Translate natural language to logical formulas.
  • S Apply resolution theorem proving techniques.
  • A Demonstrate precision in logical reasoning.
  • Lab on Logic Translation
  • Logical Proof Submission
9 Midterm Examination
  • K Assess mastery of search and logic concepts.
  • S Evaluate problem-solving skills under pressure.
  • A Reflect on academic integrity standards.
  • Midterm Examination
  • Formative Assessment Rubric
10 Introduction to Machine Learning Pipelines
  • K Describe ML pipeline architecture components.

  • A Value reproducibility in machine learning.

  • Pipeline Documentation
11 Deep Neural Networks for Computer Vision
  • K Analyze CNN architectures and feature extraction.
