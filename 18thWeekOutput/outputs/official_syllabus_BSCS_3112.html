Course Syllabus: BSCS 3112
I. Course Identification & Specification
Course Code BSCS 3112 Course Title Artificial Intelligence
Credit Units 3 Units (Lecture: 2 hrs/wk, Lab: 3 hrs/wk) Prerequisites CS 3110 (Data Structures and Algorithms)
Course Description Foundations of AI and intelligent agents
II. Course Learning Outcomes (CLOs)
CLO ID Outcome Statement (Measurable Bloom's Verb) Cognitive Level Mapped POs
CLO1 Analyze complex computing problems and identify foundational principles of artificial intelligence. Analyze PLO1, PLO5
CLO2 Design intelligent agents capable of perceiving and acting within dynamic environments. Create PLO2, PLO5
CLO3 Evaluate the effectiveness, efficiency, and ethical implications of proposed AI solutions. Evaluate PLO2, PLO3
CLO4 Create comprehensive technical documentation to communicate AI concepts in professional contexts. Create PLO1, PLO3
III. 18-Week Semester Instructional Matrix
Wk Topics Covered Lesson Learning Outcomes (LLOs) TLAs & Exercises Assessment & Evidence
1 Introduction to AI and History
  • K Analyze the evolution of artificial intelligence.
  • S Design a project proposal for AI application.
  • A Appreciate the societal impact of technology.
  • Lecture on AI History
  • Participation Rubric
2 AI Foundations and Components
  • K Identify foundational principles of AI systems.
  • S Implement basic Python scripts for data processing.
  • A Respect intellectual property in code development.
  • Lab Exercise on System Design
  • Formative Assessment Rubric
3 Types of AI and Applications
  • K Evaluate different types of AI systems.
  • S Create a case study on AI applications.
  • A Demonstrate curiosity for technological innovation.
  • Case Study Analysis
  • Quiz on AI Types
4 Machine Learning Basics
  • K Analyze supervised vs unsupervised learning.
  • S Design a dataset for classification tasks.
  • A Value data accuracy and integrity.
  • Lab Exercise on Data Preparation
  • Dataset Quality Check
5 Supervised Learning Algorithms
  • K Explain regression and classification models.
  • S Implement Linear Regression in Python.
  • A Adhere to ethical data usage standards.
  • Lab Exercise on Model Training
  • Code Review
6 Unsupervised Learning Algorithms
  • K Analyze clustering and dimensionality reduction.
  • S Design a K-Means clustering solution.
  • A Demonstrate critical thinking in pattern recognition.
  • Lab Exercise on Clustering
  • Model Evaluation Report
7 Neural Networks and Deep Learning
  • K Evaluate the architecture of neural networks.
  • S Create a basic neural network model.
  • A Appreciate the complexity of deep structures.
  • Lab Exercise on Neural Networks
  • Architecture Diagram
8 Natural Language Processing (NLP) Intro
  • K Analyze text data processing techniques.
  • S Design a tokenization pipeline.
  • A Respect linguistic diversity in NLP.
  • Lab Exercise on Text Processing
  • Pipeline Design Doc
9 Midterm Examination
  • K Demonstrate mastery of Weeks 1-8 concepts.
  • S Apply learned algorithms to solve problems.
  • A Reflect on academic integrity during assessment.
  • Midterm Examination
  • Midterm Exam Paper
10 Computer Vision Fundamentals
  • K Analyze image processing techniques.
  • S Implement object detection models.
  • A Value privacy in visual data collection.
  • Lab Exercise on Image Processing
  • Code Review
11 Reinforcement Learning Basics
  • K Evaluate Q-learning and policy gradients.
  • S Design an agent for a game environment.
  • A Demonstrate patience in iterative learning.
  • Lab Exercise on RL Agents
  • Agent Performance Log
12 AI Ethics and Bias
  • K Analyze ethical implications of AI bias.
  • S Formulate mitigation strategies for bias.
  • A Advocate for fairness in AI systems.
  • Ethics Workshop
  • Bias Mitigation Plan
13 AI Documentation and Standards
  • K Create comprehensive technical documentation.
  • S Design a user manual for AI tools.
  • A Communicate complex concepts clearly.
  • Documentation Workshop
  • Technical Report Draft
14 Capstone Project Planning
  • K Analyze requirements for AI capstone.
  • S Design a system architecture for the project.
  • A Demonstrate commitment to project goals.
  • Project Planning Session
  • Project Proposal
15 Capstone Development Phase 1
  • K Implement core AI functionality.
  • S Debug and optimize the capstone system.
  • A Collaborate effectively with team members.
  • Capstone Coding Sprint
  • Development Milestone Check
16 Capstone Development Phase 2
  • K Evaluate system performance metrics.
  • S Create final documentation and presentation.
  • A Showcase professional work ethic.
  • System Testing
  • Performance Metrics Report
17 Capstone Review and Refinement
  • K Analyze feedback from peer reviews.
  • S Refine the capstone project based on feedback.
  • A Demonstrate resilience in iterative improvement.
  • Peer Review Session
  • Refinement Log
18 Final Examination & Capstone Defense
  • K Evaluate comprehensive understanding of AI.
  • S Defend the capstone project publicly.
  • A Exhibit confidence in professional presentation.
  • Final Defense
  • Final Exam & Defense Rubric
IV. Institutional Grading System (UPHSD CCS 70/30 Formula)
Class Standing (70%) Quizzes & Drills (30%) + Research / Case Analysis (20%) + Laboratory Hands-on Tasks (50%)
Major Examinations (30%) Midterm Examination (Week 9) + Final Examination & Defense (Week 18)
Passing Criterion Final Computed Grade ≥ 75.0% (Transmuted Rating ≥ 3.00)
